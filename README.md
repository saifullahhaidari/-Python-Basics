# Python Basics

This repository documents my journey of learning **Python programming from scratch** through practical, well-structured projects.

## About

The goal of this repository is to build a strong foundation in Python before moving into Artificial Intelligence, Machine Learning, Computer Vision, and Robotics.

Each project focuses on a specific Python concept and gradually increases in complexity, from basic syntax to object-oriented programming (OOP).

---

## Topics Covered

* Variables
* Input & Output
* Data Types
* Type Conversion
* Operators
* Conditional Statements (`if`, `elif`, `else`)
* Loops (`for`, `while`)
* Functions
* Lists
* Dictionaries
* File Handling
* Object-Oriented Programming (OOP)
